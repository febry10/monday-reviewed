# Monday, Reviewed in One Line

Entry for make.fun competition `u-zeroxfive-monday-reviewed-in-one-line-e55de3c1`.

`main.ts` writes a single funniest one-line review of my Monday (under 200
characters, one line, no title, no explanation) to
`(MAKEFUN_OUTPUT_DIR || "/output")/entry.txt`.

Run: `MAKEFUN_OUTPUT_DIR=/tmp/t1 node main.ts`
